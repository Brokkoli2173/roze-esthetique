# CLAUDE.md

Website für Roze Esthétique (Beauty Studio & Academy).

## Hosting

- Das Repo wird kostenlos über **GitHub Pages** deployed (Branch `main`).
- Alles, was auf `main` gepusht wird, geht live.

## Projektumfang

- Wir arbeiten vorerst **ausschließlich an einer statischen Website**: HTML, CSS und bei Bedarf einfaches JavaScript.
- Kein Backend, keine Datenbank, keine serverseitige Logik.
- Kein Build-Schritt und keine Frameworks, solange nicht ausdrücklich gewünscht – die Dateien müssen so, wie sie im Repo liegen, auf GitHub Pages funktionieren.
- Einstiegspunkt ist `index.html` im Root.
